1. AUTHENTICATION
APIs xác thực và quản lý JWT tokens
==================================================

--------------------------------------------------
POST /auth/login
--------------------------------------------------
Tác dụng:
Đăng nhập hệ thống bằng username và password.
Trả về access token và refresh token để sử dụng cho các API bảo mật.

Request:
{
  "username": "string",
  "password": "string"
}

Response 200:
{
  "success": true,
  "data": {
    "accessToken": "string",
    "refreshToken": "string"
  },
  "message": "Login success",
  "error": null
}


--------------------------------------------------
GET /auth/me
--------------------------------------------------
Tác dụng:
Lấy thông tin người dùng hiện tại đang đăng nhập.
Dùng để xác định role và permission nhằm phân quyền giao diện.

Request:
Header:
Authorization: Bearer {access_token}

Response 200:
{
  "success": true,
  "data": {
    "id": 0,
    "username": "string",
    "fullName": "string",
    "status": 0,
    "roles": [
      {
        "id": 0,
        "name": "string",
        "code": "string",
        "permissions": [
          {
            "id": 1,
            "name": "READ_USER",
            "resource": "USER",
            "action": "READ",
            "description": "Quyền đọc thông tin người dùng",
            "createdAt": "2023-12-01T10:00:00Z",
            "createdBy": "admin"
          }
        ]
      }
    ],
    "createdAt": "2025-12-26T17:10:32.067Z",
    "createdBy": "string",
    "updatedAt": "2025-12-26T17:10:32.067Z",
    "updatedBy": "string"
  },
  "message": "string",
  "error": "string"
}


--------------------------------------------------
POST /auth/refresh
--------------------------------------------------
Tác dụng:
Làm mới access token khi token cũ hết hạn.

Request:
{
  "refreshToken": "string"
}

Response 200:
{
  "success": true,
  "data": {
    "accessToken": "string"
  },
  "message": "Refresh token success",
  "error": null
}


--------------------------------------------------
POST /auth/logout
--------------------------------------------------
Tác dụng:
Đăng xuất hệ thống, vô hiệu hóa token.

Response 200:
{
  "success": true,
  "message": "Logout success",
  "error": null
}
